# Brand Identity

## Visual Identity Guidelines

### Core Visual Elements

**Colors**
- Primary: Black (#000000)
- Secondary:
    - Coral (#FC6E53)
    - Magenta (#DB50E4)
    - Purple (#9A35EB)
- Background: White (#FFFFFF)
- Text: Dark Gray (#333333)

**Typography**
- Primary Font: Poppins
- Weights: Light (300), Regular (400), Medium (500), Bold (700)
- Headers: Poppins Bold
- Body: Poppins Regular
- Code: Monospace (Fira Code or similar)

**Design Principles**
1. Minimal - Clean, uncluttered layouts
2. Data-focused - Let the data tell the story
3. Professional - Enterprise-grade appearance
4. Accessible - Easy to read and understand
5. Consistent - Uniform across all materials

**Logo Usage**
- Minimum padding: 20px on all sides
- Never stretch or distort
- Black logo on light backgrounds
- White logo on dark backgrounds
- Minimum size: 120px width
- Clear space: 1x logo height around logo

## Content Themes & Narratives

### Tier 1 Themes (Core)
Focus on these themes primarily:
1. **Real-time Data** - Alpha signals, real-time processing, aggregations
2. **Insights** - Hidden insights in the data
3. **Data Reliability** - Uptime, consistency, accuracy
4. **Developer Experience** - Easy integration, great docs
5. **Ecosystem Growth** - Data-driven insights

### Tier 2 Themes (Supporting)
Use these as secondary angles:
1. **Cost Efficiency** - vs building in-house
2. **Speed to Market** - Launch faster with Numia
3. **Transparency** - Open metrics for communities
4. **Innovation** - Latest indexing techniques

### Storytelling Angles
Use these story frameworks for content:
- "From 0 to 1B transactions: How [Chain] scaled"
- "5 Signals hidden in onchain data"
- "How can you tell if your token incentives are working"
- "Why every L1 needs a data strategy"
- "The hidden costs of running your own indexer"
- "Building trust through transparent data"
- "Make product decisions based on data"
