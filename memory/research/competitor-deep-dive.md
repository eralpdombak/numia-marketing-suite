  - 10,000 daily calls
  - No API key required
- **Enterprise Tier:**
  - Custom limits
  - Dedicated infrastructure
  - Priority support
  - Used by: CoinMarketCap, major exchanges

**FUTURE MONETIZATION:**
Per Mintscan team: "This year, Mintscan API will be available as a service"
- Currently working on sustainable approach
- Plan to open API to developers, protocols, institutions

### Cosmostation's Primary Revenue

**Validator Commission Fees:**
- Cosmostation validates on 80+ PoS chains
- Takes 5% commission on staking rewards
- Offers 17.76% APY to delegators
- **This is their main revenue source**

**Business Model:**
1. Free Mintscan drives traffic
2. Traffic stakes with Cosmostation validators
3. Validators earn commission
4. Synergistic flywheel

**Secondary Revenue:**
- Enterprise API services
- Custom integrations for exchanges/platforms

### Mintscan's Weaknesses

## 🔄 THE GRAPH - COMPLEX TOKENOMICS

### Pricing Model

**Decentralized Pricing:**
- No fixed monthly fee
- Pay per query in $GRT tokens
- Pricing set dynamically by indexers

**Costs for Indexers:**
- Minimum stake: 100,000 GRT (~$9K at Sept 2023 prices)
- Gas fees: $77.75 average for full allocation lifecycle
- Ongoing: Signal costs, rebate calculations

**Costs for Developers:**
- Query fees in GRT (varies by indexer)
- Typical: $0.0001-$0.001 per query
- Can get expensive at scale

### The Graph's Weaknesses

❌ **Cosmos Coverage:** Only Cosmos Hub in beta
❌ **Complexity:** Tokenomics create friction for developers
❌ **High Barrier to Entry:** $9K+ to become indexer
❌ **"Not compatible with Cosmos ecosystem"** - Dune team at ETHSF
❌ **Developer-Only:** Not for analysts/researchers

**Numia Positioning:**
- "The Graph's complexity without the tokenomics headache"
- "Simple pricing: pay in USD, not crypto"
- "28 Cosmos chains vs. The Graph's 1"
- "For analysts AND developers"
