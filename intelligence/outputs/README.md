# Generated Outputs

This folder contains all written outputs saved from the Notes page, organized by platform.

## Structure

- **linkedin/** - LinkedIn posts
- **twitter/** - Twitter threads
- **blog/** - Blog posts
- **email/** - Email content
- **newsletter/** - Newsletter content

Each output is saved with a timestamp for easy reference and tracking.

## How It Works

When you click "Save to Intelligence" on the Notes page:
1. The raw output is saved to the appropriate platform folder here
2. Claude analyzes the output to extract key learnings
3. Learnings are saved to `intelligence/output-intelligence/`

This allows the AI to:
- Learn from successful outputs
- Improve future content generation
- Build a library of proven content

## File Naming

Files are named: `YYYY-MM-DD-HH-MM-SS.md`

Example: `2026-01-18-15-30-45.md`
