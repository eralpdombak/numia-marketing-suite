# Strategy & Compliance

## Industry-Specific Compliance Requirements

### Blockchain/Crypto Regulations

**Securities Compliance**
- No token sale promotion
- Avoid words: "invest", "returns", "profit"
- Focus on technology, not tokenomics
- No price speculation or predictions

**Marketing Claims**
- All performance metrics must be verifiable
- Include data sources and timestamps
- Avoid hyperbolic language
- Substantiate all competitive claims

**Open Source**
- Attribute any open-source code
- Respect licenses (MIT, Apache, etc.)
- Contribute back when possible
- Document any modifications

### Regional Considerations

**United States**
- Follow FTC guidelines for testimonials
- Include proper disclosures
- Avoid securities-related language

**European Union**
- GDPR compliance mandatory
- Cookie consent for web content
- Right to be forgotten considerations

**Asia-Pacific**
- Respect local crypto regulations
- Some regions restrict crypto marketing
- Focus on technology benefits
